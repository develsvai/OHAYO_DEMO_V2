# 결정

## Task 구성은 0 / 10부터 시작

`planningElapsed`를 Task당 구간으로 나눠 `plannedCount`를 계산한다. Prompt 제출 직후 값은 0이고 20초 단위로 증가하여 200초에 10이 된다. RESET은 Planning 시간을 0으로 지우므로 항상 동일한 생성 과정을 다시 거친다.

## 속도는 기존 전역 배속 사용

별도의 테스트용 분기나 축약 Graph를 만들지 않는다. 데모 모드의 200초 Timeline에 기존 `speed=7`을 적용해 테스트 모드에서는 약 28.6초로 재생한다.

## 생성 간격은 관객 화면에 노출하지 않음

화면에는 `Task 선별·생성 중`, 현재 개수와 Graph Node Animation만 표시한다. 발표 내부 Timing인 20초 규칙은 README와 Scenario Data에만 둔다.

## 5분 테스트 예산 갱신

자동 구간은 CLI 302초, Task 선별·생성 200초, Task 실행 1,200초, 완료 8초로 총 1,710초다. 7배속에서는 약 244초이므로 전체 5분에서 약 56초의 수동 조작 여유가 남는다.
