# 결정

## 프로젝트 루트에 문서 배치

기존 상세 문서는 `site/README.md`에만 있어 발표 시작 위치에서 바로 보이지 않았다. 프로젝트 루트에 짧은 실행 문서를 새로 만들고 상세 설정은 기존 문서로 연결했다.

## 실행 명령은 하나만 안내

호환용 `./demo_start` 설명은 제외하고 권장 명령인 `./demo-start`만 사용법에 표시해 발표자의 선택 혼란을 없앴다.

## RESET 동작을 구체적으로 명시

버튼 위치를 오른쪽 아래 구석으로 적고, Prompt·Task·Timer·일시정지·화면 모드를 초기화한 뒤 Product Prompt와 Task 0/10부터 다시 시작한다는 점을 명시했다.
