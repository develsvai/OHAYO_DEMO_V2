# 문제 해결

## 로컬 서버 권한

- 증상: sandbox 안에서 vinext dev가 0.0.0.0:9229 EPERM으로 종료됐다.
- 조치: 사용자 승인 경계를 거쳐 동일한 npm run dev를 허용된 로컬 실행으로 다시 시작했다.
- 결과: http://localhost:3000/ HTTP 200 응답을 확인했다.

## 앱 내 브라우저 미리보기

- 증상: Browser runtime에 사용 가능한 브라우저가 없어 탭을 열 수 없었다.
- 조치: 로컬 서버와 HMR을 유지하고 빌드 검증으로 진행했다.
- 후속: 브라우저 연결이 가능한 환경에서 종합 시각 QA를 수행한다.
