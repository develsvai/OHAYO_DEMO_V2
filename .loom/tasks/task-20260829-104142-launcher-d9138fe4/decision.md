# 결정

## 테스트 속도는 7×로 고정

기존 자동 진행 시간은 CLI 302초, Task Graph 8초, Task 실행 1,200초, 완료 8초로 총 1,518초다. 7배속에서는 약 217초이므로 5분 제한 안에서 `Loom 구성 계속` 클릭과 OHAYO Prompt 입력에 약 83초를 확보한다.

## 데모 모드는 기존 1× 유지

발표용 시나리오 데이터와 각 Stage·Task의 기준 시간은 변경하지 않고 Launcher에서 선택한 배속만 CLI와 Web에 전달한다. 따라서 내용과 로그 순서는 두 모드에서 완전히 동일하다.

## 실행 진입점 두 개 지원

기존 `./demo_start`를 보존하고 사용자가 요청한 `./demo-start`를 얇은 실행 별칭으로 추가했다. 두 진입점은 같은 Launcher를 실행한다.

## 선택값의 우선권 보장

일반 실행에서 별도 속도 환경값이 모드 선택을 덮어쓰지 못하게 했다. 자동 검증에서는 `DEMO_MODE=test|demo`만 허용하며 각 모드의 속도는 각각 7×와 1×로 고정된다.
