# 문제 해결

## 샌드박스에서 기존 로컬 Viewer 접근 실패

첫 TTY 검증은 샌드박스의 로컬 포트 접근 제한 때문에 기존 `localhost:3000` 서버를 감지하지 못하고 종료됐다. 허용된 로컬 실행으로 다시 검증해 1번 선택, Codex 입력 화면, STEP 1~5 완료, `speed=7` Viewer URL 출력까지 확인했다.

## 인앱 브라우저 연결 없음

로컬 Web 화면의 자동 브라우저 검사를 시도했으나 연결 가능한 인앱 브라우저가 없었다. 대신 로컬 URL의 HTTP 200 응답과 Web 코드의 Query Speed 적용 지점 세 곳(Task Graph, Task 실행, 완료)을 확인했고 정적 시나리오 검증과 production build를 통과했다. 구현 또는 배포를 막는 문제는 아니다.
