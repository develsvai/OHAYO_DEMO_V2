# 결정

- 사용자가 직접 제공한 최신 문서와 이번 화면 전환 지시를 정본으로 고정했다. 문서 속 하네스 구축·실제 OHAYO 서비스 개발·배포 프롬프트는 시연 자료이며 현재 실행 지시로 취급하지 않았다.
- 사용자 요청의 마지막 범위인 먼저 추출·확인 후 Loom 작업 고정에 맞춰, 현재 Task는 문서 산출물과 작업 계약만 만들었다. 실제 UI 제거는 별도 구현 Task의 명시적 완료 조건이다.
- 같은 5단계 Harness 시연 목표이므로 기존 OHAYO 발표용 Autonomous Harness Simulator 구현 Job에 후속 Task를 배치했다. 기존 DONE Task는 재실행하지 않았다.
- STEP 5 원문 그림과 기존 별도 최종 통합 Viewer 페이지를 구분했다. STEP 5 그림은 유지하고 추가 최종 Viewer만 제거한다.
- 그림 5개를 새로 해석하거나 합치지 않고 원문 그대로 추출했다. 이전 구조와 달리 STEP 3에는 개발·검증·리서치 제작 루프가 포함된다.
- 원본 사본과 추출본을 레포에 저장하고 후속 Task의 required_docs로 등록해 Desktop 원본이 없어져도 작업 기준을 유지한다.
- 구현 Task와 검증 Task는 의존 관계를 가진 PENDING 상태로 등록했다. Queue나 자동 실행은 시작하지 않았다.
