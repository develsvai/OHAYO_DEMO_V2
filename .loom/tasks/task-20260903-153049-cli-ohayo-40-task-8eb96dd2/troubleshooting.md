# 검증 중 확인 및 복구

첫 PTY 시험은 입력 검증을 통과했지만 캡처 저장 코드의 Path import가 빠져 시험 스크립트만 종료 코드 1을 반환했다. import를 추가하고 동일 시험을 재실행해 종료 코드 0과 정확한 제출을 확인했다.

브라우저의 미래 Task를 기다리는 locator는 짧은 도구 제한에 걸렸다. 실제 현재 상태를 읽어 24번에서 일시정지한 뒤 복원을 검증하고 나머지는 정상 타이머로 완주했다. 앱의 진행 오류나 브라우저 console error는 없었다.

임시 발표 뷰포트 캡처에서 중복 조각이 보이는 도구 캡처 현상이 있었지만 실제 DOM 크기·스크롤 위치·노드 경계를 확인했다. 브라우저 90% 배율 때문에 1440×900 요청의 CSS 영역은 1600×1000이었다. 임시 뷰포트는 해제했다.

연속 붙여넣기 사이에 CRLF 상태가 남지 않도록 새 paste 시작 시 초기화했다. 수정 후 실제 PTY 시험을 다시 통과했다. 미해결 차단 사항 없음.
