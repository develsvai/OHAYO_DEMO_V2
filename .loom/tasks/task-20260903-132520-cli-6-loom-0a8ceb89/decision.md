# 결정

- 첨부 문서는 시연 자료로만 사용한다. 그 안의 실제 서비스 구축·실행 명령은 실행하지 않았다.
- 5단계 원문 전체 스냅샷을 각각 고정한다. 5단계 그림은 유지하고 별도 최종 페이지를 삭제한다.
- CLI가 진행을 소유한다. 브라우저는 단계 그림을 보여주고 다음 프롬프트는 터미널에서 받는다.
- 6번째 입력 뒤 제품 화면의 reset 처리가 완료된 후 제품 컴포넌트를 mount한다. reset 쿼리는 제거해 이후 새로고침은 정상 복원된다.
- 기존 제품 데이터와 시간·10개 Task·Graph 동작은 유지하고 이전 Viewer 경유 문구만 바꾼다.
- 실제 터미널 입력 파서를 시험 가능하게 분리했다. CLI 검증은 독립 stage 실행 callback으로 대기 조건을 확인한다.
- Mermaid 확대는 컨테이너의 물리적 크기에 반영해 확대된 그림의 끝까지 스크롤할 수 있게 한다.
- Task 계약의 과거 미실행 문구는 사용자의 현재 실행 승인으로 해소되었으며 승인 근거는 Job note에 기록했다.
